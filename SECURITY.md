# Security Policy

## Supported versions

This project does not currently publish a stable release line or support window. Security fixes are evaluated against the default branch.

## Reporting a vulnerability

Report suspected vulnerabilities privately to the repository owner. Do not open a public issue containing credentials, personal data, exploit details, or other sensitive material.

Include the affected revision, reproduction conditions, impact, and any suggested mitigation. Remove secrets and private data from logs or screenshots before sharing them.

The owner will confirm receipt and communicate next steps through the same private channel. No response-time commitment is currently published.
